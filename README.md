## 🚀 نصب و راه‌اندازی

### پیش‌نیازها
- Node.js **18+**
- npm یا yarn

### مراحل نصب

```bash
# ۱. کلون پروژه
git clone https://github.com/MobinDe/Admin-Dash-React.git

# ۲. ورود به پوشه
cd Admin-Dash-React

# ۳. نصب وابستگی‌ها
npm install

# ۴. اجرای dev server
npm run dev
